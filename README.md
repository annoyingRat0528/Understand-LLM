# A Comprehensive Guide To Help You Truly Understand LLM!

5 `Jupyter Notebook`s that makes LLM easier to understand! This repository is focused on the GPT-2 model which comes out along with the OG "Attention Is All You Need" paper. (https://arxiv.org/pdf/1706.03762)

I have a fully working GPT model right in the 5th notebook, feel free to check out!

Based on **Vizuara** "Build a LLM from scratch" series. If you are interested, you may go to their YouTube channel (https://www.youtube.com/@vizuara) to enjoy the fun of exploaration even better.
